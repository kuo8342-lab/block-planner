教練

每週日花 10 分鐘排下週，比每天臨時想要做什麼輕鬆很多。

想問更多：教練會讀你這週真的排了什麼、做了多少再回答。每次提問會用到你自己 API 金鑰的額度。

各科時數

「完成」只算你打勾的方塊。達成率 = 完成 ÷ 排了；對目標 = 完成 ÷ 目標。

這週的夜空

每完成一個方塊亮一顆星，越久越大；紅圈是時間過了沒做的，虛線是還沒到的。亮度 = 這週完成 ÷ 每週目標。

      外觀

      主題會同步到你所有裝置（包括桌面便利貼）。動畫開關只記在這台裝置上；系統設定「減少動態效果」時，動畫會自動關閉。

      作息

      每個人的作息不一樣，開夜車也沒關係。時間表的範圍和睡覺時間都照你的習慣設定，改完會重新整理。

      提醒與聲音

      任務的「提醒我」在每個任務旁邊勾選，會在整點、:15、:30、:45 跳出鬧鐘。

      分段：專注和休息輪流，直到專注時間加起來等於方塊或任務的分鐘數，最後一段不足就做剩下的時間。不分割：一次倒數完，中間不休息。

      放假與地區

      固定行程

      每週固定的事（補習、社團…）用斜線顯示，方塊會避開。點時間表上的固定行程可以這週取消或永久刪除，刪除後 1 天內可以在這裡復原。

      AI（用你自己的金鑰）

      目標拆解和教練要用 AI。選一家 AI 服務，貼上你在那家建立的 API 金鑰就會出現。費用由你自己的 API 帳戶支付，建議在那家的後台設定每月花費上限。Google Gemini 的 Flash 系列目前有免費額度（以 Google 官方公告為準；免費額度的內容 Google 可能拿去改進產品）。金鑰只存在這台裝置，不會傳給這個網站，只會直接送到你選的 AI 服務。

      取得金鑰

      資料與隱私

      資料只存在這台裝置的瀏覽器裡，不會上傳到任何伺服器。換裝置或清除瀏覽器資料就會不見，記得定期匯出備份。

      「下載備份檔」會把你所有的方塊、任務、目標和設定存成一個 .json 檔，放到這台裝置裡（手機會跳出分享畫面，選「儲存到檔案」或傳給自己）。換裝置或清除瀏覽器資料前先下載一份，到新裝置按「匯入備份」就能還原。這不是提醒功能。

      會刪掉每週的方塊、任務、願望清單、範本和目標，無法復原，建議先匯出。
