步調 Pace・桌面便利貼（Windows）

這是什麼
  一張貼在桌面上的便利貼，顯示現在該做什麼、今天接下來的行程和這週任務。
  它直接讀你的步調同步帳號，不需要開著瀏覽器。

怎麼用
  1. 把這個資料夾放在一個不會刪掉的地方（例如「文件」），點兩下 pace-note.vbs。
  2. 打開步調網站 → 設定 → 同步，先登入，再按「連結電腦桌面便利貼」。
  3. 回到桌面，點一下便利貼。看到今天的行程就完成了。

什麼時候更新
  開啟時、點一下便利貼時、每 5 分鐘自動一次。
  電腦關機或便利貼被關掉時不會更新；第一次執行後它會跟著 Windows 一起啟動。

操作
  拖曳      移動位置
  點一下    立刻同步
  連點 5 下 打開步調網站
  右鍵      立刻同步、打開步調、解除連結、開機時自動啟動、關閉

隱私
  連結碼等於你的登入，不要貼給別人。便利貼讀到後會清掉剪貼簿。
  登入資料只存在這台電腦的 %APPDATA%\PaceNote，並用你的 Windows 帳號加密。
  便利貼只讀資料，不會修改你的計畫。要登出：右鍵 → 解除連結。

移除
  右鍵 → 取消「開機時自動啟動」→ 關閉便利貼，再刪掉這個資料夾和 %APPDATA%\PaceNote。
