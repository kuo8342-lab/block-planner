步調 Pace・桌面便利貼（Windows）

這是什麼
  一張貼在桌面上的便利貼，顯示現在該做什麼、今天接下來的行程和這週任務。
  它直接讀你的步調同步帳號，不需要開著瀏覽器。

怎麼用
  1. 打開步調網站，登入同步，到選單的「便利貼」頁。
  2. 按「安裝桌面便利貼」，打開下載的「安裝步調便利貼」。
  3. 等幾秒，便利貼出現在桌面上，而且已經連好帳號。
  已經裝好、只是要重新連結：在同一頁按「連結桌面便利貼」。

檔案
  setup.cmd      使用者下載的安裝檔（只有英文字，內容是去網站讀 setup.ps1）
  setup.ps1      真正的安裝步驟：下載下面兩個檔到 %LOCALAPPDATA%PaceNoteapp 並啟動
  pace-note.ps1  便利貼本體；pace-note.vbs 用來不帶黑視窗地啟動它
  網站的 /note/ 由 pace-build/build-c.js 每次建置時從這個資料夾複製。

什麼時候更新
  開啟時、點一下便利貼時、每 5 分鐘自動一次。
  電腦關機或便利貼被關掉時不會更新；第一次執行後它會跟著 Windows 一起啟動。

操作
  拖曳      移動位置
  點一下    立刻同步
  連點 5 下 打開步調網站
  右鍵      立刻同步、打開步調、解除連結、開機時自動啟動、關閉

隱私
  連結碼等於你的登入，不要貼給別人。便利貼讀到後會清掉剪貼簿。
  登入資料只存在這台電腦的 %APPDATA%\PaceNote，並用你的 Windows 帳號加密。
  便利貼只讀資料，不會修改你的計畫。要登出：右鍵 → 解除連結。

移除
  右鍵 → 取消「開機時自動啟動」→ 關閉便利貼，再刪掉這個資料夾和 %APPDATA%\PaceNote。
